KANJI MASTER ANDROID PROJECT

ဒီ ZIP သည် Android Studio ဖြင့် APK တည်ဆောက်နိုင်သော project ဖြစ်သည်။
ပါဝင်သောအရာများ:
- Offline Japanese / Myanmar / English Kanji flashcards (36 entries)
- Dictionary search
- Quiz: Meaning and Reading
- Learned progress and quiz score saved on device
- Japanese text-to-speech (ဖုန်းတွင် Japanese voice ရှိပါက)
- Kanji tracing canvas

APK တည်ဆောက်ရန်:
1. ZIP ကိုဖြည်ပါ။
2. Android Studio တွင် KanjiMaster folder ကို Open လုပ်ပါ။
3. Android SDK Platform 35 နှင့် JDK 17 ရှိကြောင်း စစ်ပါ။
4. Build > Build Bundle(s) / APK(s) > Build APK(s) ကိုနှိပ်ပါ။
5. APK ကို app/build/outputs/apk/debug/app-debug.apk တွင် ရနိုင်သည်။

GitHub Actions ဖြင့်:
1. Project ကို GitHub repository အသစ်သို့ upload လုပ်ပါ။
2. Actions tab > Build Kanji Master APK > Run workflow ကိုနှိပ်ပါ။
3. အောင်မြင်လျှင် KanjiMaster-debug-apk artifact ကို download လုပ်ပါ။
4. ZIP ထဲမှ app-debug.apk ကို Android ဖုန်းတွင်ဖွင့်ပြီး Install လုပ်ပါ။

မှတ်ချက်: ဒီ project မှထွက်လာသော debug APK သည် test / personal install အတွက်ဖြစ်သည်။
